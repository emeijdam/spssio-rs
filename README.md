# SPSSIO-RS

Ergonomic Rust bindings for the SPSSIO C Module, generated using the excelent rust [bindgen](https://github.com/rust-lang/rust-bindgen).

Inspired by the [duckdb-rs](https://github.com/duckdb/duckdb-rs) bindings.

[IBM SPSS Statistics 29 IO Module](https://community.ibm.com/community/user/ai-datascience/viewdocument/extensions-tools-and-utilities-for?CommunityKey=886b6874-0fb1-402c-8243-c70ef8179a99&tab=librarydocuments)

## Usage

```rust
use std::error::Error;
use spssio::SPSSFile;

fn main()-> Result<(), Box<dyn Error>>{
    let myfile = SPSSFile::open_write("output.sav")?;

    myfile.set_var_name("var1", 0)?;
    myfile.set_var_label("var1", "Variable 1")?;

    myfile.commit_header()?;

    myfile.set_value_numeric("var1", 123.45)?;
    myfile.commit_case_record()?;
    
    myfile.set_value_numeric("var1", 678.90)?;
    myfile.commit_case_record()?;

    myfile.close_write()?;

}
```

More examples can be found in the examples folder.

## Use Cases
Generated by Gemma-3-27b-it:

SPSS-rs opens up possibilities for integrating SPSS data into the Rust ecosystem. Here are some potential use cases, categorized by complexity:

**1. Simple Data Extraction & Transformation (Current Status - Good)**

*   **Data Cleaning/Preprocessing:** Read `.sav` files, perform basic cleaning operations in Rust (handling missing values, recoding variables), and output cleaned data to CSV or Parquet.
*   **Statistical Summaries:** Calculate descriptive statistics (mean, median, standard deviation) for specific variables within an SPSS file.
*   **Data Subsetting/Filtering:** Extract a subset of cases based on specified criteria. Useful for creating smaller datasets for testing or analysis.

**2. Integration with the Rust Data Science Ecosystem (Near Future)**

*   **Data Analysis Pipelines:** Integrate SPSS data directly into larger Rust-based pipelines, leveraging libraries like `ndarray`, `linfa` (machine learning), or `statrs`.
*   **Data Validation:** Validate the integrity of SPSS datasets before further processing. Check data types, value ranges, and consistency.
*   **Automated Data Import:** Build tools to automatically import SPSS files into databases or other storage systems.

**3. Advanced Statistical Modeling & Machine Learning (Future Development)**

*   **Custom Statistical Algorithms:** Implement custom algorithms in Rust that operate directly on SPSS data.
*   **Machine Learning Feature Engineering:** Create new features from SPSS variables for use in machine learning models.
*   **Bayesian Analysis:** Integrate SPSS data into Bayesian statistical modeling frameworks implemented in Rust.

**4. Specialized Applications (Long Term)**

*   **SPSS Data Archiving/Migration:** Develop tools to migrate datasets to newer formats or archive them.
*   **Auditing & Compliance:** Build systems that audit files for compliance with regulatory requirements.
*   **Web Application Integration:** Serve SPSS data through a Rust-based web API.

**Note:** This project is under active development.  The current focus is on providing robust bindings for basic data access and manipulation, enabling the use cases in sections 1 & 2. More advanced features will be added over time.

## Building on and for OSX.
As far as I know, IBM is working on SPSS Statistics for Apple Silicon, so we're currently compiling for Rosetta.

cargo run --target x86_64-apple-darwin    
cargo build --target x86_64-apple-darwin   

cargo build -vv --target x86_64-apple-darwin  


## Building for Linux

install_name_tool -add_rpath @executable_path SPSS-RS

export RUSTFLAGS="-C link-args=-Wl,-rpath,@executable_path"
cargo build --target x86_64-apple-darwin

cargo run --example create_sav --target x86_64-apple-darwin
